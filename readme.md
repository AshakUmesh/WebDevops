# WebDevops — Frontend Development Projects

A collection of hands-on web development projects built while learning HTML, CSS, and JavaScript. Each project targets a specific set of concepts — from DOM manipulation and event handling to responsive layouts and CSS animations.

---

## Projects

### 🎵 Spotify Clone
A static front-end clone of Spotify's UI. Focuses on replicating a production-grade layout using Flexbox and CSS Grid, including sidebar navigation, song cards, and a bottom playback bar.

**Concepts:** Flexbox, CSS Grid, responsive layout, UI cloning

---

### 🐶 TinDog
A landing page for a fictional dog-dating app, inspired by Tinder's design. Built with Bootstrap for responsive grid and components.

**Concepts:** Bootstrap, responsive design, navbar, hero sections, pricing cards

---

### 🖼️ 3D Image Slider
An interactive image carousel with a 3D rotation effect using CSS `transform` and `perspective`. No JavaScript libraries — pure CSS animation with JS for controls.

**Concepts:** CSS 3D transforms, `perspective`, `rotateY`, JS event listeners

---

### 🍽️ Recipes Website
A multi-page recipe site with a clean card-based layout. Demonstrates page linking, semantic HTML, and consistent styling across multiple views.

**Concepts:** Semantic HTML5, multi-page structure, CSS cards, typography

---

### ✅ To-Do List
A dynamic to-do app where tasks can be added, checked off, and deleted. Demonstrates core DOM manipulation patterns.

**Concepts:** DOM manipulation, `addEventListener`, `createElement`, local state management

---

### ❌ Tic Tac Toe
A two-player Tic Tac Toe game with win detection logic and a restart button. Built entirely in vanilla JavaScript.

**Concepts:** Game logic, 2D array state, conditional rendering, event delegation

---

### 📂 JavaScript Exercises
A folder of standalone JS practice scripts covering fundamentals — loops, functions, arrays, objects, and ES6 features.

**Concepts:** ES6+, array methods, closures, arrow functions

---

## Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Structure and semantics |
| CSS3 | Styling, Flexbox, Grid, animations |
| JavaScript (ES6+) | Interactivity and DOM manipulation |
| Bootstrap | Responsive layout (TinDog) |

---

## How to Run Any Project

All projects are plain HTML/CSS/JS — no build step needed.

```bash
git clone https://github.com/AshakUmesh/WebDevops.git
cd WebDevops/<project-folder>
# Open index.html in your browser
```

Or just open `index.html` directly in any browser.
